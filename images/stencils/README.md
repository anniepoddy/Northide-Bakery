# Folk stencils

Original brush-stroke motifs in the Polish folk-painting and Bolesławiec pottery tradition, drawn for Northside Bakery (free to use on packaging, signs and social). Made by `tools/folk-stencils.py`.

Each motif comes in navy (`#22338F`) and black, as:
- `.svg`: sharp at any size; in Canva you can recolor it. Best for print, vinyl cutting and laser cutting.
- `.png`: transparent background, 4× size.

Motifs: `daisy-stem`, `daisy-leaves`, `double-daisy-stem`, `tulip-spray`, `medallion`, `spray`, `peacock-eye`. `_preview-sheet.png` shows them all.

Everything is one solid color with the highlights cut out, so the shapes also work as real paint stencils or rubber stamps.
