# "100% Family Recipe" badge

Scalloped seal for the front of the pierogi bag, matching the Canva design's navy `#091386`, gold `#E8CC8B` and cream `#F2E9D8`.
Ring text: "Authentic Polish Food" (top) and "Northside Bakery · Est. 1992" (bottom), with folk daisies.

- `badge-cream-navy.png`: cream center, navy ring. Best on the cream bag, overlapping the pierogi.
- `badge-navy-gold.png`: navy with gold lettering, matching the logo.
- `badge-gold-navy.png`: gold ring, navy center, for the most shelf pop.

Each PNG is 1600 × 1600 px with a transparent background. To change the wording, edit the `badge-*.html` file and re-render it with Playwright.
